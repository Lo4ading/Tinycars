# Tiny Cars · Medien

Bilder und Videos für Instagram und Pinterest (öffentlich, für Metricool).

- `img/`   – Tuch, Bases, Makro-Details (fertig im Format 4:5)
- `foto/`  – neue Fotos: fertiges Stück, Vorher/Nachher, Werkstatt, Hand, Vitrine
- `video/` – Reels im Hochformat 9:16
- `story/` – spontane Fotos für Stories
