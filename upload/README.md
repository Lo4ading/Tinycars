# upload/

Neue Fotos und Videos hier hochladen (GitHub-App oder github.com → „Add file“ → „Upload files“).

- Dateinamen egal, gern mit kurzer Notiz im Namen, z. B. `zeitraffer-malen.mp4`
- Max. 25 MB pro Datei über die Weboberfläche/App (GitHub-Grenze); größere Videos vorher kürzen
- Claude prüft den Ordner, bearbeitet die Dateien, verschiebt sie nach foto/, video/ oder story/ und leert upload/ danach wieder
